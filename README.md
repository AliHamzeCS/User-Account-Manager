# 🔐 User Account Manager

A Python-based User Account Manager built as a learning project to practice Object-Oriented Programming, Regular Expressions, SQLite database management, input validation, decorators, and modular programming.

## 📌 Version

Current Version: `v1.1.0`

## ✨ Features

### 👤 Account Management
- 📝 User registration
- 🔑 User login
- 🧱 User Class using Object-Oriented Programming

### 🔎 Validation
- 👤 Username validation using Regex
- 📧 Email validation using Regex
- 📱 Phone number validation using Regex
- 🔐 Password validation using Regex

### 🗄️ Database
- SQLite database integration
- 🆔 Automatic user ID generation
- 🚫 Duplicate username detection
- 🚫 Duplicate email detection
- 🚫 Duplicate phone number detection

### 🛠️ Other Features
- 🎨 Colored terminal output using Colorama
- 🧩 Custom decorator system
- 🔄 Input validation loops
- 📦 Modular project structure

## 🛠️ Technologies

- Python 3
- SQLite
- Regular Expressions (Regex)
- Colorama
- Object-Oriented Programming (OOP)
- Decorators
